SCROLL MOTION
Animations are tied to scroll progress using GSAP ScrollTrigger scrub. Scrolling down advances each motion; scrolling up reverses it. This is movement/3D camera motion, not just fade-in/fade-out. Try slow scrolling through the About, Projects, Future Tech and Certificates sections.
